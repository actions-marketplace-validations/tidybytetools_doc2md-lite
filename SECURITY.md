# Security

## Supported versions

Only the newest release of doc2md-lite gets fixes.

## Report a problem

Please do not open a public issue for a security problem.

Use GitHub's private report form instead:
https://github.com/tidybytetools/doc2md-lite/security/advisories/new

Tell us what you found and how to make it happen again. We will reply as soon as we can, and we will credit you if you want.

## What this tool does

doc2md-lite runs on your own computer. It does not send your files anywhere. It has no accounts, no API keys and no tracking.
